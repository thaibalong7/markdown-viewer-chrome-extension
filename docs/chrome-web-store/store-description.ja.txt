Markdown Plus は、Chrome で使える無料の Markdown ビューア・リーダーです。ローカルの .md ファイルをブラウザで直接開き、Markdown のソースではなく、読みやすく整えられた文書として表示できます。アカウントの登録やドキュメントのアップロードは不要です。

主な機能

• ローカルの Markdown を表示 — .md、.markdown、.mdown、.mdc に対応。
• フォルダ内を参照 — フォルダを開き、ファイルパネルから読みたいドキュメントを選択。
• 長い文書の見出しへ移動 — アウトラインから読みたいセクションを選択。
• コードを読みやすく表示 — コードブロックのシンタックスハイライト。
• 表やタスクリストを表示 — 構造のある内容も見やすく整形。
• Mermaid の図を表示 — ドキュメント内で図を確認。
• 数式を表示 — 文中の数式も、別行の数式も KaTeX で表示。
• Markdown の拡張機能に対応 — 脚注、絵文字、GitHub 形式のアラート。
• 閲覧テーマを選択 — ライト、ダーク、ハイコントラスト。
• 読みやすさを調整 — フォント、文字サイズ、行の高さ、本文の幅を設定。
• カスタムテーマを作成 — 配色を変え、背景画像やアニメーションを追加。
• 関連ファイルを表示 — ファイルパネルからテキスト、SQL、DBML、Mermaid、画像を開く。
• 図や画像を詳しく確認 — 拡大表示して、ズームやドラッグで見たい部分を確認。
• 外部での変更を検出 — 開いているファイルの変更を検出し、読み込むタイミングを選択。
• 変更内容を比較 — 追加・削除された行や、影響を受ける Markdown のセクションを確認。
• ライブプレビューで編集 — 実験的エディタを有効にして、選択した元のファイルに保存。
• ドキュメントをエクスポート — Markdown を HTML または Word 互換の .doc ファイルに保存。
• 図をエクスポート — Mermaid の図を SVG または PNG でダウンロード。
• 印刷・PDF 保存 — Chrome の印刷画面を使用。
• 最近使ったファイルを開く — 以前開いたローカルの Markdown ドキュメントに戻る。
• 設定をバックアップ — 設定とカスタムテーマの構成を JSON で保存・復元。背景画像は含まれません。
• 表示言語を選択 — 英語、ベトナム語、簡体字中国語、スペイン語、ドイツ語、日本語、ルーマニア語に対応。「設定」→「全般」で変更できます。

すべて無料

すべての機能を無料で利用できます。有料サブスクリプションやアップグレードの購入は不要です。

使い始めるには

1. Markdown Plus をインストールします。
2. chrome://extensions を開き、Markdown Plus - Free Markdown Viewer の「詳細」（Details）を選びます。
3. 「ファイルの URL へのアクセスを許可する」（Allow access to file URLs）をオンにします。
4. Chrome でローカルの Markdown ファイルを開くか、再読み込みします。

Chrome 116 以降が必要です。Markdown Plus はローカルの Markdown ファイルを開くと有効になります。その他の対応形式を開くには、先に Markdown ビューアを開いてから、ファイルパネルでファイルを選んでください。

編集機能は実験的な機能で、初期状態ではオフです。保存するには元のファイルを選択し、書き込みを許可する必要があります。

プライバシー

ドキュメントの内容はブラウザ内で処理され、開発者が運営するサーバーにはアップロードされません。設定は Chrome 経由で同期される場合があります。最近使ったファイルのパスと背景画像は端末内に保存されます。ドキュメントから外部の画像が読み込まれる場合や、数式を含むエクスポート済みドキュメントが外部 CSS を参照する場合があります。
