# Markdown Plus Workspace

> A focused local workspace for reading, navigating, editing, and exporting Markdown without leaving Chrome.

## Everything in one calm view

Markdown Plus turns local notes into a polished reading experience. Keep your files close, move through a complete workspace, and use the Outline to jump directly to the section you need.

## Built for real documents

- [x] Browse Markdown, text, SQL, Mermaid, and images

## Private by design

Your local documents are processed in the browser. Markdown Plus does not operate a server that receives their contents.

## A workspace that stays yours

Choose a built-in light or dark theme, tune typography from the Popup, or create a reusable custom theme in Theme Studio.
