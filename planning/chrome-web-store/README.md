# Chrome Web Store planning

Approved upload images live together in [`../../assets/chrome-web-store/`](../../assets/chrome-web-store/). This planning folder contains submission preparation, reusable demo data, and editable artwork sources.

- [`release-checklist.md`](./release-checklist.md): remaining release, packaging, and manual QA tasks.
- [`submission-guide.md`](./submission-guide.md): Vietnamese step-by-step account registration, dashboard preparation, review submission, and publishing instructions.
- [`release-notes-1.0.0.md`](./release-notes-1.0.0.md): public release notes and known limitations for the chosen 1.0.0 version.
- [`release-candidate-1.0.0.md`](./release-candidate-1.0.0.md): candidate artifact, verification evidence, and pending user QA.
- [`privacy-disclosure.md`](./privacy-disclosure.md): draft dashboard disclosure text; compare it with current policy and runtime before submission.
- [`store-listing.md`](./store-listing.md): copy-ready description, one-time file-access setup, and reviewer instructions.
- [`privacy-permissions-verification.md`](./privacy-permissions-verification.md): privacy/permissions evidence, checks, and remaining deployment/dashboard/onboarding gates.
- [`screenshots/`](./screenshots/): demo workspaces, capture notes, and local raw/composition working files.
- [`promotional/`](./promotional/): editable Editorial Frost composition, renderer, and retained local alternatives.

Raw captures, screenshot composition intermediates, promotional alternatives, comparison sheets, and ZIP bundles stay local through scoped `.gitignore` entries. Approved PNGs are versioned under `assets/`.
