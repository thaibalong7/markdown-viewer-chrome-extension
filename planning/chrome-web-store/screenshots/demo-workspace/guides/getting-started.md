# Getting Started

## 1. Open a Markdown file

Choose a local `.md` document in Chrome. Markdown Plus replaces the raw text with a dedicated reader while keeping your file local.

## 2. Open a workspace

Use **Open folder…** in the Files panel to browse related Markdown, text, SQL, Mermaid, and image documents.

## 3. Make it yours

Open the extension Popup to change the theme, typography, editor preferences, plugins, or recent-file history.

## 4. Export when ready

Use document actions to print, export HTML or Word, and download Mermaid diagrams as SVG or PNG.
