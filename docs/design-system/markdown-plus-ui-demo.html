Viewer-first design system

The running Viewer is the canonical visual reference for Markdown Plus. New surfaces reuse its semantic colors, system typography, radii, focus treatment, and state language.

Documentation follows runtime source. It does not introduce a second visual direction.

Foundation

The interface uses a neutral blue-gray canvas, a white reading surface, compact rails, and semantic interaction states. Normal structure is separated by borders; shadows are reserved for temporary floating layers.

  • Blue communicates navigation, focus, and active selection.
  • Green communicates successful completion and saved state.
  • Amber communicates editing, dirty state, and warnings.
  • Red communicates failure and destructive actions.

Runtime layout

Read mode uses three tracks: Files, document content, and a right rail containing document actions plus Outline. The document article stays transparent inside the surface-colored content pane instead of becoming a raised card. 

.mdp-body {
  grid-template-columns:
    var(--mdp-files-width)
    minmax(0, 1fr)
    var(--mdp-toc-width);
}

Interaction states

Active rows use a soft blue fill and leading accent rail. Icon actions are compact on fine pointers and expand to 44px on coarse pointers. Focus always remains visible.

ElementFine pointerCoarse pointer
Action icon34px44px
Outline row36px44px
Text button38px44px

Extending the system

Settings and future Popup work should derive application controls from these Viewer foundations. They may use page-specific layouts, but must not introduce alternate palettes, font stacks, focus rings, or status semantics.

Source of truth: src/theme/index.js and src/viewer/styles/**. Use the controls in the right rail to preview theme and rail states. Open the component catalog for future application primitives.
