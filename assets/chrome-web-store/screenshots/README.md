# Store screenshot sources

Reusable capture fixtures for the 1.0.0 release. The [approved upload set](../README.md) records image order, dimensions, and feature focus; the [release record](../../../docs/chrome-web-store/release-1.0.0.md) records launch context.

- `demo-workspace/`: primary showcase with Markdown, Mermaid, SQL, text, and images.
- `demo-workspace-two/`: secondary workspace for folder switching.

Raw captures (`raw/`, `raw-v2/`), compositions, render scripts, and intermediates (`compositions/`) remain local and ignored by Git. Preserve RGB/no-alpha screenshot output. Use a clean profile and demo paths for future captures; remove personal paths, recent history, profile details, cursors, and unrelated browser UI.
