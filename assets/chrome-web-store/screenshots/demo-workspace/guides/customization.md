# Customization Guide

## Built-in themes

Choose from Light, Dark, Sakura, Matcha, Dracula, Gruvbox, Night Owl, Aurora Glass, and accessibility-focused high-contrast themes.

## Custom themes

Theme Studio lets you choose a foundation, tune semantic colors, select a bundled syntax theme, and add a local gradient or image background.

## Reading preferences

Font family, font size, line height, content width, table of contents, scrollbars, and document statistics can all be adjusted without leaving Chrome.
