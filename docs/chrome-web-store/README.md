# Chrome Web Store release reference

The current release is **1.0.1**, published on **2026-11-10** on [Chrome Web Store](https://chromewebstore.google.com/detail/markdown-plus/afbdmkpldpbkmmhejjlajocpneaiipmk). See the [1.0.1 release record](./release-1.0.1.md) for package metadata and release scope.

This release includes Find/workspace search, seven interface languages, matching website editions, and the Store listing copy for **Markdown Plus - Free Markdown Viewer**. The [submission form guide](./submission-form.md) and [listing copy](./store-listing.md#detailed-descriptions) remain reusable references for future updates.
