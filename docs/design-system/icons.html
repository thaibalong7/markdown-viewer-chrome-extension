Usage & design rules

Use 16px in lists, 18–20px for actions, and 24px for larger specimens. File identities are authored at 16px; application glyphs scale from 24px. Keep hit targets separate from artwork size.

One primary metaphor

A clock means document tracking; a download arrow applies a revision; two columns with plus/minus mean review. Collapse folders uses two overlapping layers and a minus, separate from upward navigation.

Color follows purpose

Application icons use currentColor and semantic states. Explorer identities keep their fixed palette; selected rows provide the selection background. Include accessible names and tooltips on icon-only controls.

Shared geometry

Viewer, Popup, Settings, code blocks, and lightboxes use the same local definitions. No icon font, CDN, or SVG markup from user content is involved.

Design references

The chosen direction uses consistent geometry, familiar metaphors, and clear silhouettes at actual UI sizes. The 1.8 stroke is specific to Markdown Plus.

  • Lucide — Design principles: grid, stroke consistency, negative space, and optical balance.
  • IBM — UI icon design: consistent visual weight while preserving each symbol’s proportions.
  • Google — Material Symbols: adapt weight and optical treatment to context; keep the explorer family separate.
