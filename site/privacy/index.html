Privacy Policy

Markdown Plus is designed to process your local documents in your browser. The developer does not operate a server that receives your document content.

Effective date: September 20, 2026

Scope

This policy applies to the Markdown Plus Chrome extension. It explains what information the extension handles, where that information is stored, and when a network request may occur.

Information processed on your device

When you choose to open or edit a supported local document, Markdown Plus processes its content, file name, and local file URL or path in Chrome to provide viewing, navigation, editing, saving, printing, and export features. This processing happens locally in the browser. Document content is not sent to a server operated by the Markdown Plus developer.

Information stored by the extension

  • Reader, editor, explorer, theme, and plugin preferences are stored with chrome.storage.sync when it is available. Chrome may sync those settings through the Google account signed in to Chrome. If sync storage is unavailable, the extension uses chrome.storage.local instead.
  • If recent-file history is enabled, local file URLs, file names, and last-opened times are stored only in chrome.storage.local on the current Chrome profile. Recent-file paths are not placed in sync storage.
  • When supported and after you select a file for saving, Chrome may allow the extension to retain a file handle in browser IndexedDB. This lets later saves target the same file. Chrome remains responsible for file-system permission prompts and controls.

Network requests

Markdown Plus does not upload local document content to a developer-operated service. However, the extension does not promise zero network requests in every workflow:

  • A document can reference remote images or other resources. Chrome may request those resources from the host named in the document, which can receive standard request information such as your IP address and browser headers.
  • An exported HTML or Word-compatible document containing Math may reference KaTeX CSS from cdn.jsdelivr.net. Opening that exported file while online may contact jsDelivr. The extension itself bundles the styles it uses to display Math in Chrome.
  • External links are opened only when you choose to follow them.

Those third-party services process requests under their own privacy policies. Markdown Plus does not receive data from those requests.

Sharing and sale

The developer does not sell, rent, or share your document content, local file history, stored file handles, or preferences. The extension does not use this information for advertising, credit decisions, or profiling.

Permissions

  • file:///* lets the extension recognize, read, and display local files.
  • storage stores preferences and recent-file history as described above.
  • offscreen supports reading local documents and directory listings for the Files explorer.
  • downloads supports HTML, Word-compatible, and image exports, plus save fallbacks when a direct file write is unavailable.

Your controls

You can disable recent-file history and clear its entries in Markdown Plus settings. You can reset extension preferences, revoke file access in Chrome, clear the extension's site data, or uninstall the extension. Uninstalling removes extension-managed browser storage according to Chrome's behavior; exported files remain wherever you saved them.

This website

The developer does not add analytics, advertising, forms, or cookies to this public policy site. The site is hosted by GitHub Pages, so GitHub may process technical request data under the GitHub General Privacy Statement.

Changes to this policy

Material changes will be published on this page with an updated effective date. The repository history provides a public record of revisions.

Contact

For privacy questions or support, open an issue in the Markdown Plus GitHub repository.
